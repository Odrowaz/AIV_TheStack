# AIV_TheStack
Consegna del primo progetto in Unity per il secondo anno di AIV

Progetto svolto da **Domenico Landriscina**

## Istruzioni

Aprire la **SampleScene** nella cartella `Scene`.

## Comandi

- **WASD** - Movimento Camera
- **Click Sinistro Mouse** - Spostare Oggetti
- **Click Destro Mouse** - Spawnare Oggetti
- **Rotella Mouse** - Avvicina e allontana oggetti quando sono selezionati con il click sinistro
